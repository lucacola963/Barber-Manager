# ✂️ Barber Manager

Mini gestionale per barber shop.

## Funzioni

- Registrazione dei servizi effettuati
- Gestione collaboratori
- Gestione listino prezzi
- Storico dei servizi
- Statistiche per collaboratore
- Esportazione dei dati
- Backup locale

## Tecnologie

- Python
- Flask
- SQLite
- HTML/CSS

## Nota

L'applicazione non è collegata alla cassa e viene utilizzata esclusivamente per registrare e analizzare i servizi effettuati dai collaboratori.
